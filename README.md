# 笔记助手 (Note Helper) v2.0

本地文本整理工具，v2.0 升级为「笔记 / 待办」双模式。

## 🆕 v2.0 更新

- 新增 **待办 / 笔记双模式**：一键切换文本整理与待办清单
- 新增 **搜索**：笔记模式高亮匹配行，待办模式实时过滤条目
- 新增 **快捷短语**：日期、时间、邮件、签名一键插入，支持自定义短语
- 保留全部文本整理工具，并扩充「清空」按钮
- 注入 SOLCAT 彩蛋引擎，UI 全面美化

## 功能

- **笔记模式**：去首尾空格、压缩空行、去重行、排序行、转大写、转小写、清空
- **待办模式**：添加 / 勾选 / 删除待办，本地持久化
- **统计**：笔记模式显示字符 / 词数 / 行数；待办模式显示任务 / 已完成 / 剩余
- **搜索高亮**：匹配内容用 `<mark>` 高亮显示
- **快捷短语**：点击插入到光标处；右键短语可删除，点「+ 自定义」添加
- **导出 TXT**：按当前模式导出文本内容

## 使用方法

1. 打开 `index.html`
2. 用顶部切换按钮选择「笔记模式」或「待办模式」
3. 在搜索框输入关键词，笔记模式查看匹配行，待办模式过滤列表
4. 点击快捷短语插入常用文本

## 🥚 彩蛋秘籍

| 操作 | 效果 |
|------|------|
| ↑ ↑ ↓ ↓ ← → ← → B A | 全屏彩带烟花 |
| 连点标题 5 次 | 开发者模式面板 |
| 输入 `solcat` 后回车 | 赛博朋克隐藏主题 |
| Ctrl + Shift + T | 切换赛博朋克主题 |

**本作专属**：解锁任意彩蛋后，会插入隐藏内容（笔记模式插入 Markdown 标题，待办模式新增彩蛋任务）。

## 技术栈

纯 HTML / CSS / JavaScript，localStorage + Service Worker。整理操作保持纯函数设计。
